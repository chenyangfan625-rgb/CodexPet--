# AI 制作记录

本项目为 AI 生成的非官方《原神》同人动画，与米哈游 / HoYoverse 无合作、隶属或背书关系。角色设计的原有权利归相应权利人。

## 创作目标

以桑多涅和哥伦比娅为双人陪伴组合，保持黑红金、白紫的服饰配色与可识别的头饰轮廓。默认让桑多涅坐着，哥伦比娅趴在她膝上；两种方向状态使用更明显的互动动作。

## 最终动作设计

- 日常：膝上贴贴，发丝与身体有轻微跟随动作。
- 向左：两人都站立，桑多涅在画面左侧，哥伦比娅在右侧。桑多涅握住她肩膀或上臂，屈伸手肘带动她前后轻晃；双脚保持着地。
- 向右：桑多涅坐姿和凳子保持固定。哥伦比娅先从身后拥抱哄她，再沿同侧靠近到正面拥抱，最后退回身后形成循环。

## 制作过程

1. 人工提供角色造型、互动图片和动作视频参考，提出和修订动作要求。
2. 使用 OpenAI 图像生成工具生成基础画面、状态帧及造型修订稿。
3. 提取生成帧，统一每格尺寸、人物比例和落点。
4. 清理绿色背景及边缘残留，保留服饰中的浅青色和金色装饰。
5. 组装九种动画状态与十六个视线方向，生成 PNG、WebP、GIF 和 MP4。
6. 检查动作衔接、透明边缘、跳跃高度和视线方向，整理本公开包。

最终 PNG 的结构检查通过；本包的可复跑检查结果见 qa/release-validation.json。检查脚本检验文件与布局，不评价画面是否完全符合官方设定。部分视线过渡幅度较小，仍保留 AI 绘制细节和低帧数动画的风格。

公开版本保留完成后的资源与制作摘要，没有完整生成环境或随机种子，不能承诺重新生成时得到逐像素相同的图像。未重新分发制作工具、编码器、原始参考图片/视频、生成服务记录或账户数据。
